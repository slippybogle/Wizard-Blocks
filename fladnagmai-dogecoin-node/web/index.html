Dogecoin NODE

Dogecoin Core v1.14.9, pruned, txindex off. Used by Wizard-Blocks-LTC for mining.

Sync progress: open Wizard-Blocks-LTC (its node panel shows height and sync state), or run on the Umbrel:
sudo docker exec fladnagmai-dogecoin-node_dogecoind_1 sh -c 'dogecoin-cli -datadir=/data -rpcport=22555 -rpcuser=$RPC_USER -rpcpassword=$RPC_PASS getblockchaininfo'

The first sync downloads the whole chain once; on a home connection that takes days.
