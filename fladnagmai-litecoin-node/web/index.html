Litecoin NODE

Litecoin Core v0.21.5.8, pruned, txindex off. Used by Wizard-Blocks-LTC for mining.

Sync progress: open Wizard-Blocks-LTC (its node panel shows height and sync state), or run on the Umbrel:
sudo docker exec fladnagmai-litecoin-node_litecoind_1 sh -c 'litecoin-cli -datadir=/data -rpcport=9332 -rpcuser=$RPC_USER -rpcpassword=$RPC_PASS getblockchaininfo'

The first sync downloads the whole chain once; on a home connection that takes days.
